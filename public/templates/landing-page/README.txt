EDITABLE HTML & CSS TEMPLATE — ISAAC, KENYA

1. Extract the complete ZIP into a separate folder. No CoderTech website files are required.
2. Open index.html in a browser for a preview. Internet access is not required.
3. Use VS Code on desktop or Acode on Android to edit the HTML text and links.
4. Colours and fonts are at the top of styles.css in :root. Keep the stylesheet beside the HTML pages.
5. Termux: pkg install python
   Open the extracted folder: cd /path/to/template
   Run: python -m http.server 8000
   Open http://localhost:8000 in your browser.
6. Copy sections into an existing site and adapt class names if they conflict. No npm, framework or build step is needed.
7. Replace all sample names, pricing, metrics and links with your real information.
8. Forms are UI demonstrations only. Connect your own secure service before publishing. Authentication screens do not create accounts, sign users in, store passwords or send email. Never store real passwords in HTML or browser storage.
